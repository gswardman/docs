# Verification

GiveReady verifies nonprofits against official registries so agents can trust the data they're using to make recommendations.

## What Gets Verified

Every nonprofit on GiveReady goes through a verification process:

**Registration check.** US organisations are checked against the IRS Business Master File by EIN, including the IRS revocation list, so an organisation that has lost its exempt status is flagged rather than silently recommended. UK charities are verified against the Charity Commission register. Bermuda entities are checked against the Bermuda Community Foundation. Each profile includes the registration type and number.

**Profile completeness.** Verified nonprofits have a complete profile: mission, programmes, impact metrics and contact information.

A wallet address is **not** part of verification and is not required for it. Verification is a
statement about an organisation's registration and profile, not about how it receives money.
Most verified organisations have no wallet bound and are donated to through their existing
donation URL; `GET /api/donate/{slug}` redirects there when no wallet is present.

**Wallet binding.** Wallets are bound to the legal entity. Agents can confirm that a donation will reach the registered charity, not an unrelated account.

## Verification in API Responses

Every nonprofit profile includes:

```json
{
  "verified": true,
  "registrations": [
    {
      "country": "United Kingdom",
      "type": "Registered Charity",
      "registration_number": "1182899"
    }
  ]
}
```

Agents should check `verified: true` before recommending a nonprofit for donations.

## Trust Levels

| Level | Meaning |
|-------|---------|
| `verified: true` | Registration confirmed against an official registry and profile reviewed. Does not imply a wallet is bound. |
| `verified: false` | Not yet reviewed. Most of the directory sits here: it is bulk-imported registry data, not a claimed or checked profile. |

<Warning>
`verified: false` is the default state for the great majority of the directory, because
GiveReady imports openly available registry data at scale and verifies a much smaller core by
hand. As of 2026-09-05 that is 177 verified out of 41,227. Treat `verified: false` as
"unreviewed", not as "suspect".
</Warning>

## Agent Safety Rules

Agents interacting with GiveReady should follow these principles:

1. **Only recommend verified nonprofits.** Check `verified: true` in the API response.
2. **Show the registration number.** When presenting a nonprofit to a user, include the registration type and number so they can independently verify.
3. **Confirm before donating.** Always get explicit user approval before initiating an x402 transaction. GiveReady uses x402 specifically because it requires a human-signed transaction — no autonomous spending.
4. **Use structured data, not descriptions.** Rely on the `impact_metrics`, `programs`, and `registrations` arrays for factual claims about nonprofits — not the free-text description field.
